# Bob Yan

Personal site published at [bobby-24.github.io](https://bobby-24.github.io).

Static files. `index.html` is the introduction and timeline, `research.html` is the projects, and `about.html` is the rest. The header switches between the paper theme and a Kanagawa night theme.

Pushing `main` updates the site. `.nojekyll` keeps GitHub Pages from treating these notes as pages.
